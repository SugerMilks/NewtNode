# Frame It mannequin

NewtNode's Frame It figure, `frame-it-mannequin.glb`, is based on the **3D Male Base Mesh (Rigged)** released by Orange Juice Games and maintained for Godot by BoQsc.

- Source: https://github.com/BoQsc/Godot-3D-Male-Base-Mesh
- License: Creative Commons Zero v1.0 Universal (CC0-1.0)

The mesh is used as a neutral posing figure with NewtNode materials and Frame It controls.
