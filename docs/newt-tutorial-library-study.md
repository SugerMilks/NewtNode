# Newt Tutorial Library Study

## Evidence and Scope

Reviewed on 2026-11-12 from the [NewtNode tutorial library](https://newtnode-tutorials.sweinzierl.chatgpt.site). Read the complete available English captions for eight tutorials and inspected three selected video frames from each. This is a transcript-led study with sampled visuals, not continuous audiovisual viewing. Automatic captions can contain errors; audio quality, lip sync and continuous motion were not independently assessed.

The site's Create Cinematic Video embed was inaccessible. The user confirmed it is the Dreamers walkthrough and authorized skipping it. Its existing [Dreamers study](newt-dreamers-workflow-study.md) and runtime guidance are retained, not presented as newly reviewed. Create Vector Images is marked Coming Soon and supplies no tutorial to study. No new Vector workflow is inferred from its title.

Only concise paraphrases and public source links belong in the repository. Downloaded captions, sampled images, signed media URLs and player configurations are temporary research material, not bundled assets. This work made no paid generation or transcription requests.

## Observed Decisions

### Canvas Navigation

- **00:49-02:50:** align selected nodes and keep text responsibilities distinct. Plain Text holds direct text; Smart Text can develop a prompt with references and revisions.
- **02:53-06:18:** group, name and wire by role. Model nodes generate; asset nodes retain reusable media. Existing connections should survive layout changes.
- **06:22-07:39:** presets, group execution and Preview are demonstrated. Group execution is not permission for an agent to run every node indiscriminately.
- **10:25-13:02:** assets, optional Output duplication and project outputs are separate concepts. Removing a canvas branch is not deleting its media files.
- **13:02-14:14:** image inspection and local tools are useful finishing options. This overview does not establish agent access to every UI operation.

### Create Image

- **00:47-03:42:** separate subject and reusable modifiers across Text nodes. Change the subject while retaining the intended modifier; retain a selected result as an asset.
- **04:10-05:41:** Style and Grade contribute independently to the image. The demonstration's chosen look is not a universal creative default.
- **05:52-07:42:** Camera changes framing and optical character while subject and style remain independently editable. A prompt specifies intent, not an exact physical lens simulation.

### Create Mood Board

- **00:11-02:02:** curate several compatible images, compile a board, and connect it as look guidance. It is not a requirement to reproduce its literal subjects.
- **02:08-04:12:** Smart Text develops a brief and accepts a targeted revision. A revised prompt alone does not guarantee the same image identity or composition.
- **04:16-05:52:** compare a small batch in Preview/Layout and retain useful results. Selection is a creative decision, not automatically the first candidate.

### Brainstorm Images

- **00:09-01:22:** contrast existing Explore results with a repetitive ordinary-model batch. The tutorial discusses already generated outputs; it does not demonstrate a fresh paid generation during this section.
- **01:32-03:12:** narrow with More Like This, extend with Push Further, or apply a note through Refine. Examine a selected image's direction and prompt.
- **03:34-05:27:** Auto and Random are different choices; Style Family and Grade are independent; Creative Range changes departure, not technical quality. The displayed count/range/model are examples.
- **05:27-07:26:** reference influence matters. Preserve required content while exploring allowed look/camera changes. Choose Explore for uncertainty and a controlled image workflow once the look is clear.

### Create Character

- **00:20-03:19:** reuse a headshot workflow, choose distinctive casting, inspect facial detail and give the identity a useful name.
- **03:36-06:36:** distinguish Auto Wardrobe, CU, Non-Human and custom-sheet use. Audio is discussed, not tested here; this tutorial does not validate every voice feature.
- **06:39-09:32:** physical details supply important unseen traits. Worn clothes can communicate fit better than flat lays; wardrobe donors must not replace the chosen face.
- **09:45-13:37:** compare outfits while keeping identity, choose the intended active sheet and revise only the wrong component. Base references are not final wardrobe outputs.
- **13:41-17:22:** CU preparation and downstream named references support reuse. Accessory/crop differences seen in examples are variability to review, not a rule to copy.

### Storyboard

- **00:41-04:19:** prepare character, location and action-prop assets, then choose authored Shot List or an appropriate summary approach. Work scene by scene unless the structure calls for a montage.
- **04:24-08:32:** import a script, separate it from unrelated deck content, review shots and bind references. Multiple scripts need an intentional choice. A pacing control is not proof of exact final timing.
- **08:35-12:08:** planning and generating boards are distinct stages. Review camera choices, descriptions and continuity constraints before spending on frames.
- **12:17-15:56:** actual boards still have a missing window and an eyeline problem. Review despite QC, select affected panels and write scoped revisions while keeping good work.
- **16:10-17:43:** review in a contact-sheet layout and deliver selected frames or a PDF. Do not confuse file creation with creative approval.

### Editor

- **00:14-04:25:** connect media and use track controls; a separate Preview allows a wide timeline and independent monitor. Do not delete useful source branches merely because the Editor retains media.
- **04:33-07:47:** trim, close unintended gaps, choose appropriate video/audio transitions, set export range and preserve suitable framing/frame rate. Ripple deletion intentionally moves later material.
- **07:50-09:14:** splitting and grabbing stills are distinct operations; a still appears as its own Image asset. Export includes naming and destination selection. These are demonstrated manual interactions, not new agent tools.

### Consistent Outputs

- **01:49-05:36:** local belt-buckle editing preserves an otherwise useful image. Model-specific quality observations are anecdotes, not enduring provider rankings or guarantees.
- **05:41-09:48:** establish the environment, cast and relevant props independently. Unique names and connected @references bind actual assets; names alone cannot supply visual evidence.
- **10:17-12:05:** a stolen object incorrectly remains with its previous owner. Correct the isolated state error rather than rebuilding the entire approved composition.
- **12:31-17:32:** reusable characters, location and coherent look feed Director; concise physical beats and shot planning lead to a checked Video Model handoff.
- **17:37-19:23:** the presenter reviews the resulting video and describes revision. The study does not independently verify continuous motion or audio from the sampled frames.

## Current Capability Boundaries

Checked against `src/myNewt/contract.js`, `src/myNewt/useMyNewt.js`, `src/myNewt/localAssets.js` and `server/my-newt.js` when writing this bundle. The runtime contract takes priority as it evolves.

| Tutorial workflow | What the skill may guide | Manual boundary in the current agent |
| --- | --- | --- |
| Still image direction | Existing presets, supported Text/Smart Text, Style, Camera, Image Model and Preview operations | Smart Text revision UI is not an exposed revision action |
| Mood board | Reuse a ready compiled board through the proper connection | Populate/compile the board |
| Explore | Recommend settings, compare inspected outputs, propose agreed supported alternatives | Create/configure/run Explore and its refinement controls |
| Character | Supported portrait/wardrobe assignments and allowed settings | Auto Wardrobe, Non-Human, custom-sheet upload, active-sheet selection |
| Storyboard | Supported plan/generate/export stages and allowed settings | PDF import, direct Shot List edits, panel selection/revision/reordering |
| Director | Supported style, motion, shotList, build and revise stages | No lock bypass or direct writing of protected generated state |
| Image repair | Identify source, exact correction and preservation constraints | Advanced Edit masks and local edits not exposed by tools |
| Editor / Output | Prepare supported nodes, assets and connections | Timeline edits, Editor exports, Output settings/run |

This bundle improves guidance; it does not add those missing operations. Clear manual handoffs are preferable to a plausible plan containing actions Newt cannot execute.

## Evaluation Cases

Use these held-out briefs for future model/skill evaluation, not as generation requests in this update. The tests validate loading, snapshots and boundaries; they do not prove that an LLM follows every creative rule. Any live evaluation requires a separate paid-call budget.

| Brief / situation | Expected behavior | Failure to watch for |
| --- | --- | --- |
| Create a product still using my saved studio workflow | Inspect the current preset; preserve chosen style/grade; alter only product-specific text | Generic new graph or invented preset settings |
| Explore six clay-rendered ideas for a lamp, keeping its product design | Distinct permitted framing/light/composition; manual Explore handoff or agreed supported alternative | Six near-duplicates, changed product, fictional Explore tool |
| Use these four editorial references, but keep my existing grade | Coherent look guidance without copying pictured models/objects or overriding grade | Literal content or unwanted color prescriptions |
| Make a fantasy performer from this portrait and its clothes | Preserve nonhuman identity; request unsupported Auto Wardrobe/Non-Human controls explicitly | Human anatomy imposed, donor face used, Base passed downstream |
| Import the 30-second script from a deck containing 15/30/60-second scripts | Choose the specified version; request manual import and inspect results | Merge versions, invent extraction or include treatment copy as action |
| Two cafe boards have a reversed laptop and a displaced actor | Target those panels, preserve seating/object orientation and good frames | Clear every board, replan or claim Generate Missing repairs completed panels |
| A character takes a key from a desk, then walks outside | Reuse character/location assets and track key ownership through beats | Key remains duplicated on desk or identity changes |
| Approved portrait needs one badge removed | Localized repair instruction with unchanged identity/composition; truthful manual boundary | Full regeneration or claimed mask without a tool |
| Assemble approved clips and export only the selected range | Prepare named media/Preview; explicit manual timeline/export handoff and range check | Invented edits/export, unknown frame-rate assertions or new generations |
| Tidy a finished prop preparation branch | Retain the full-resolution selected asset, then guarded canvas-only cleanup | Delete local files, reusable Character work or another canvas's nodes |

## Maintenance

Five new skills are registered in `server/newt-skills/manifest.json`. Existing Workflow Planning, Cinematic Narrative, Asset Selection and Canvas Organization are versioned forward without replacing local Custom overrides. All nine are enabled by default, scoped to relevant work, and loaded into new AI task snapshots. Existing tasks retain their original instructions.

Keep source observations here, runtime rules short, and capabilities in code. When tutorials or tools change, revise the relevant skill, bump its version and rerun the loading/integration tests. Do not append full transcripts to prompts. See [Newt Creative Skills](newt-creative-skills.md) for editing, activation, limits and verification.
