# Ideogram Vector

Vector is a dedicated graphic-design node. It uses the existing enabled Fal key; it does not require a direct Ideogram account or a new stored credential. Add it from the Nodes palette next to Image Model.

## Workflow

The expanded editor requires a backend restart and browser refresh. Existing nodes, connections and saved versions remain compatible; no regeneration is needed.

1. Choose **Text to vector** for a new design or **Vectorize image** for an existing image.
2. Write a design brief, or connect a Text/Smart Text prompt. Graphic presets help express logo, icon, sticker, illustration and typography intent in the submitted prompt; they are creative instructions, not extra API parameters or an additional LLM call.
3. For generation, optional connected image references guide the subject or composition. Connect a locked Mood Board to the separate pink **Mood Board** input for visual direction. For conversion, connect exactly one source image. Conversion uses the source directly without a prompt or Mood Board guidance.
4. Choose **Generations** (1-6, default 1) beside Generate. Each successful generation appends a variant and preserves previous work. Browse variants on the fitted checkerboard preview; double-click the image to expand it. SVG and PNG files remain saved with the project.
5. Connect the image output to Preview, Image Model or other compatible image nodes. These receive the PNG companion so existing raster-only provider contracts keep working.

Drag the large preview or any saved thumbnail onto the canvas to create an image node from its full-resolution PNG, with SVG/alpha metadata retained. Clicking a thumbnail still selects it; dragging an older thumbnail does not change the current selection. Saved variants stay draggable during generation. Save unsaved layer edits first before dragging that particular variant; other saved variants remain available. **Save Version** stays beside the Edit Artwork button for existing unsaved drafts, including after reopening a project. Local save progress and errors stay visible without opening the editor.

The SVG keeps supported paths, groups, fills, strokes, transforms, clips and gradients editable in a vector editor. The preview background is a viewer setting, not a background-removal operation. The API does not promise editable font text, exact brand colors, transparent backgrounds, print color profiles, or a specific number of shapes. Include creative requests in the brief and inspect the delivered artwork.

The compact preview has no background/Fit dropdowns or expand icon. Checkerboard and automatic fit apply to older saved nodes too. Focus the image and press Enter or Space as a keyboard alternative to double-click. Save layer edits before expanding the PNG preview, so it matches the artwork. Source comparison remains available when an image is connected; the separate Layers editor keeps its background and zoom controls.

The node is a wide workspace with artwork across the top. Saved thumbnails, Edit Artwork and the output sit directly beneath it. Brief and connections occupy the left column; design direction, lettering, palette, font/layout references and generation settings occupy the right. Status and generation actions share the bottom row. Smaller windows stack the sections without hiding settings. Existing nodes use the layout automatically without changing their contents or connections.

## Mood Board direction

In **Text to vector**, connect the compiled, locked Mood Board to the pink input. Settings and input rows are always visible, including when opening older projects that saved them collapsed. The board guides palette, shapes, linework, texture and visual rhythm; the prompt asks for one coherent design without copying the board's subjects, text, logos or collage layout. Explicit brief, lettering, palette and subject references take precedence. This is prompt guidance, not a guarantee of exact style separation. There is deliberately no Style-node input.

The board counts as one reference image. All connected subject images and boards share the five-reference limit and 10 MB per-image validation. The cost estimate includes board references, including the High-quality reference tariff. There is no additional LLM analysis or generation call, and connecting a board never starts a run.

Existing Mood Board connections on the general image input are preserved and receive the same look-only instructions during generation. **Vectorize image** continues converting its original source unchanged: the dedicated Mood Board input becomes inactive, its saved connection is retained, and the board is not sent or counted for conversion. A legacy board connected as the source image remains the source being converted.

## Font and layout references

In **Text to vector**, the two compact controls below Lettering add optional art direction:

- **Font Reference** accepts a PNG/JPEG/WebP specimen or a local TTF/OTF/WOFF/WOFF2 font file (up to 10 MB). Font files are decoded only in the browser. Choose sample lettering and Apply Reference to save a rendered PNG; only this image is sent to Fal. A saved sample remains usable after reopening or sharing the project without installing or sharing the font. To rerender different lettering, choose the typeface from the list or select the custom font file again. Use fonts you have permission to use. The picker checks a catalog of 77 Mac families, showing those available on the current computer in five style groups. Sans Serif, Serif and Monospace system defaults are always available.
- **Draw Layout** opens a blank canvas matching the current aspect ratio, or reopens the saved layout at its original dimensions. Optionally choose a connected subject or current artwork as an underlay. Pen, eraser, line, rectangle, ellipse, arrow and text-label tools share colors, size, opacity, undo/redo, clear and zoom. Applying stores both editable strokes and a full-size PNG; it does not generate artwork. Cancel discards only changes made in the popup. Existing references and generations remain intact if a local save fails.

The checkbox beside a saved guide includes/excludes it without removing its data. Remove detaches the guide, not its local file. Saved drawings, specimens and optional backgrounds travel with workflow packages; temporary browser font objects and blob URLs do not.

The named catalog follows [Apple's included/downloadable Mac fonts](https://support.apple.com/en-us/120414). NewtNode does not install fonts; enable missing downloadable fonts in Font Book, then reopen Font Reference. The app uses only local font faces and never redistributes their binaries. These are macOS-supplied fonts, not a claim that all are open-source or freely redistributable: Apple's [macOS license, section 2E](https://www.apple.com/legal/sla/docs/macOSSequoia.pdf) distinguishes display/printing from font embedding. SF/New York developer-font downloads are not included. On Windows and other systems, the list reflects available faces rather than silently substituting an unrelated font.

Reference order is layout first (primary composition), subject images, font sample, then dedicated Mood Boards. Prompt guidance assigns distinct roles so sketch arrows/labels are not copied into finished artwork, font sample words are not mistaken for requested lettering, and boards guide look rather than subject/layout. The node's **Lettering** field controls the exact requested wording. These are visual instructions, not guaranteed positioning, font matching, or editable live text.

All connected images, boards, font and layout guides share the five-reference limit. Disable/remove an extra guide or disconnect an image if the limit is exceeded. They use the existing reference-aware estimate; no additional model, LLM analysis or generation beyond the selected count is added. **Vectorize image** retains but ignores these guides and still converts its one source. Existing settings, generated variants, Layers and outputs are unchanged. Save and refresh the frontend to activate this update; no backend restart is required.

## Layers and alpha

The former Layers button is now **Edit Artwork**. The Layers tab keeps organization controls; Properties shows controls relevant to the selection. All operations below are local, undoable and free, with the original preserved by Save Version:

- Hold **Shift and drag** in the normal selection tool to draw a box and add intersecting elements to your current selection, including when starting over selected artwork. Shift-click still toggles individual elements, and Escape cancels an active box. Hidden/locked elements are skipped, and isolated groups select only their own contents. The separate **Box select** tool remains available; Shift/Command adds there too. Double-click a selected group to work inside it; Escape or the breadcrumb returns to the whole artwork.
- **Properties** offers rotation, horizontal/vertical flip, alignment and distribution. One selected object aligns to the canvas; multiple objects align to their combined bounds. Distribution needs at least three objects. The magnet enables edge/center snapping; Alt bypasses it during a drag.
- **Colors** exposes solid fills and strokes. Choose a swatch, select its replacement and apply to the selection or all artwork. Alpha is preserved; gradient stops are not edited by this control. Locked artwork must be unlocked before changing its colors.
- **Add editable text** creates live text using installed fonts. **Replace with Text** hides selected original outlines and creates a text layer in their place; it does not recognize or reconstruct the old lettering. Set the actual words, font, size, weight, spacing, line height, alignment and color. Valid changes appear immediately on the artwork while editing; **Apply Text** keeps them as one undoable edit, and **Cancel** restores the prior artwork. Apply or cancel the text before saving a version. SVG text may substitute fonts on other computers; use the PNG when exact rendered appearance matters. Fonts are not embedded or transmitted.
- With nothing selected, Properties offers **Fit Canvas** and padding. This fits visible content without revealing previously clipped off-canvas shapes or deleting hidden layers. SVGs with relative dimensions or root masks/clips keep their original canvas rather than risking appearance changes.

The comparison icon beside Edit Artwork opens **Compare Versions** for two or four saved results. Rename variants, mark one approved, or choose **Use Version** to make it the node's output. Approval does not generate or export anything. Save a draft before comparing that variant.

**Saved looks** stores design settings and optional font/layout/Mood Board guidance without copying your brief or generated artwork. References are copied into managed local storage. Connected Mood Boards override saved-board references; saved references are visible and removable. The usual five-reference limit still applies. Removing a saved look does not delete files used by an existing project.

Connect **Output** for delivery: Original/PNG uses the selected raster artwork, **SVG (Vector artwork)** uses its editable SVG companion, and **Alpha matte (PNG)** extracts white opaque/black transparent/gray partial opacity. Output retains its naming, folder and no-overwrite behavior. Save Selection first to deliver an individual group.

Open **Edit Artwork** on a generated variant for the large artwork canvas and right-hand layers panel. The node stays compact. The layer tree displays frontmost objects first, with thumbnails, groups, visibility and locks. Search finds objects inside collapsed groups; large lists are paginated.

Click the artwork to select a visible object/group; Alt-click selects inside a group. Shift/Command/Ctrl-click on the artwork adds/removes individual selections, and modified clicks on empty space retain them. In the layer list, Command/Ctrl-click toggles individual rows; Shift-click selects a sibling range, or adds a layer in another folder. Command/Ctrl-Shift adds a range without dropping previous selections. Double-click a name or press F2 to rename. Drag layer rows within a group to change stacking order, or use the forward/backward arrows. Delete, opacity, grouping and ungrouping are undoable. Groups carrying clipping, opacity or inherited paint stay grouped; pure move/scale transforms can be safely distributed during ungrouping. Locked layers protect child/parent structural edits while remaining independently showable/hideable.

Use **Group** or Cmd/Ctrl-G to put selected elements into a named folder, even when they are separated in the list or inside ordinary nested folders. Selected children of an already-selected folder are included only once. Their positions and relative order are retained; the new group is placed at the frontmost selected position, which can change overlaps with unselected artwork. Undo restores the original stack. Layers cannot be pulled out of a folder with clipping, opacity or inherited styling: select that whole folder or group its contents inside it instead. Hover over an unavailable Group button for the reason. Use **Ungroup** or Cmd/Ctrl-Shift-G to separate safe folders. A new folder immediately offers a name field. Folders have item counts and expand/collapse controls. The **Organize** folder icon remains conservative: it gathers adjacent loose top-level shapes into Artwork folders, separates actual text objects into Lettering folders, and leaves existing groups and background/locked/hidden elements intact. It preserves stacking order and is one undo step. This is free structural organization, not AI object recognition; the optional Auto Name action can help name groups afterward.

Opening **Edit Artwork** automatically organizes recognizable text and background elements into **Text** and **Background** folders. This uses actual text objects, explicit SVG lettering labels and known background objects, with no AI charge. Unlabeled lettering drawn as ordinary paths stays untouched; select those pieces and use Group. Existing folders and locks are respected. Elements separated by other artwork receive separate numbered folders rather than changing their stacking order.

The first opening also checks an untouched result for an obvious solid canvas background. When found, it is named **Background** and hidden automatically, without changing matching colors elsewhere in the artwork. Undo or the Background visibility switch restores it. Ambiguous backgrounds are left alone; a name alone never causes an element to be hidden. The combined first-open setup is one undo step. Your choice is remembered across reopening, including Undo or Cancel. Older results receive the new grouping review once while preserving existing drafts and background choices. Save Version creates the edited output while preserving the original. Automatic grouping requires the updated backend (`vectorLayerAutoGroups`, editor v5).

Drag inside the selected artwork's bounding box to move it. Drag a corner to scale proportionally, hold Shift for free resizing, or hold Alt to resize from the center. Side handles resize one axis. Arrow keys nudge one image pixel; Shift-arrow moves ten. Multiple selected layers move/scale together. A group containing a locked layer cannot be transformed. Escape during a drag cancels that gesture without closing the editor; each completed drag is one undo step. Artwork is still clipped to its original canvas on export, so undo if an object is moved out of view.

Moving and resizing are local SVG edits with no AI generation or charge. The on-canvas preview updates while dragging and saved SVG/PNG/alpha outputs retain the changes. This extension requires the updated backend (`vectorLayerTransforms`); existing nodes and previous versions remain compatible.

Use zoom controls or +/- and pan with the hand tool or Space-drag. Command/Ctrl-Z undoes; Shift-Command/Ctrl-Z redoes; Delete removes selected unlocked layers. **Cancel** (or Escape with confirmation) restores the draft present when the editor opened. Saves create new versions; a project/source change closes the editor and cannot receive a stale save.

Ctrl-Y also redoes. These layer shortcuts work with toolbar, menu or slider focus and after committing a rename; typing in a name/search field retains normal text undo. Shortcuts cannot undo the node canvas behind the popup. The layer-list scrollbar has a dedicated gap beside the eye/lock icons, and the node's Layers entry uses a bordered button with hover and keyboard-focus states. These UI refinements need only a saved-project browser refresh, not a backend restart.

Existing names and neutral shape labels are free. **Auto Name Layers**, the wand above the layer list, optionally asks your enabled vision API for names for up to 32 selected layers (or root layers when none are selected). It confirms the possible charge first, makes one analysis call, and presents editable suggestions before Apply Names. Naming never changes shapes, groups or pixels; uncertain fragments may retain neutral names. This is not automatic object segmentation. Ordinary editing never calls an AI provider.

To remove a background, select its objects and use **Mark selected objects as background**, then switch **Background** off. This changes only the assigned objects, not every white shape. Clear removes the assignment without changing visibility. The preview's checkerboard setting alone does not remove a background.

**Save Version** creates a new variant containing an editable SVG, a PNG with alpha and an alpha-matte PNG. The original is retained. The matte is white for opaque areas, black for transparency and gray for partial opacity. Existing visible backgrounds remain opaque until hidden. The saved PNG is the image sent to connected Preview/Output nodes and dragged onto the canvas; SVG and alpha companion files remain in the project's output storage. Unsaved edits remain in the node's preview and must be saved before dragging or publishing the changed result. The node no longer displays the extra download/count/dimensions row or footer captions.

**Save Selection** creates one separate variant from the selected objects together, retaining canvas dimensions, positions, transforms, clipping and opacity. Unselected objects remain hidden in the SVG so shared resources and editable source content are not lost. Select individual objects and save separately when separate files are needed. Hidden selected objects or hidden ancestors stay hidden.

These are SVG object/group controls, not AI semantic segmentation, PSD layers or native Illustrator layers. Names are stored as SVG titles; support in other editors varies. The layer editor supports up to 5,000 objects and 500 edits per saved version; more complex originals can still be downloaded. Editing, rasterization and matte creation run locally with no provider charge; optional AI naming is billed separately. Saved drafts, locks and all companion assets survive project copy/save/import. A failed local save keeps the draft and previous results. Editor v2 requires the backend's `vectorLayerEditor` capability.

## Provider contract

Verified October 26, 2026 from [Ideogram Vector](https://ideogram.ai/models/vector/), [Fal text-to-vector API](https://fal.ai/models/ideogram/vector/text-to-vector/api) and [Fal image-to-vector API](https://fal.ai/models/ideogram/vector/image-to-vector/api).

| Operation | Fal endpoint | Controls |
| --- | --- | --- |
| Text to vector | `ideogram/vector/text-to-vector` | Prompt 1–9,500 characters including composed instructions; quality `low`, `medium`, `high`; aspect ratio; optional seed 0–2,147,483,647; up to five references, at most 10 MB each |
| Vectorize image | `ideogram/vector/image-to-vector` | One JPEG/PNG/WebP up to 50 MB; `mode: default` or `simple` |

The Generations selector requests 1-6 SVGs, defaulting to 1 for both new and existing nodes. The batch runs sequentially through the existing API and saves each completed result immediately. Prompt, references and settings are captured at Run; edits during generation apply to the next batch. A fixed seed advances by one for each result (wrapping after 2147483647); blank uses random seeds. Text references are validated before upload. No provider fallback or paid-request retry is allowed.

The run button shows the total batch estimate when API Cost is enabled; History records individual outputs. Failure, Stop Waiting or leaving the mounted node stops unstarted generations and preserves completed work. Check recovers the current request only, never automatically starts the rest of the batch. Save/reopen retains the selected count, outputs and current receipt. The generation-count update needs only a frontend refresh, not a backend restart.

Supported generation ratios: Auto, 1:1, 1:4, 1:3, 1:2, 9:16, 10:16, 2:3, 3:4, 4:5, 5:4, 4:3, 3:2, 16:10, 16:9, 2:1, 3:1 and 4:1. Vectorization follows the source. There is no raster resolution control for editable geometry; PNG dimensions are recorded from the delivered SVG.

Fal and direct Ideogram have different parameter names. The direct API uses `/v2/svg/generate/ideogram-vector-1` and `/v2/svg/vectorize/ideogram-vector-1`, ratios such as `1x1`, and vectorization modes `auto`, `simple`, `detailed`. Those direct-only fields must not be sent to Fal. Reference: [Ideogram generation](https://developer.ideogram.ai/v2/api-reference/vectors/generate-svg), [Ideogram vectorization](https://developer.ideogram.ai/v2/api-reference/vectors/image-to-svg).

## Cost and request lifecycle

Published per-SVG estimates are Low $0.13, Medium $0.16, High $0.20 without references, High $0.32 with references. Image conversion costs $0.10 per image. Costs are estimates until a request-specific settled charge is available. The workspace API Cost preference governs run-button labels; History and Stats retain recorded amounts and provenance.

Every request has an idempotency identifier. Repeated actions cannot silently submit the same request twice; a changed payload cannot reuse that identifier. Stop waiting detaches the UI from a submitted request. It does not guarantee that Fal cancels computation or billing. The server continues saving completed work to History. Do not immediately rerun an uncertain request; inspect History first. **Check existing request** retrieves an already submitted result without generating again. Private receipts under ignored `server/data/ideogram-vector/` retain request IDs and credential fingerprints, never keys. Recovering an unfinished provider request requires its original enabled Fal key; completed local results remain available. Reopening, copying or importing nodes does not generate media.

Vector is manual-only for Run All and Newt. Automatic generation requires future integration with the agent's approval, budgeting and request-journal lifecycle.

## Storage and safety

Generated SVGs are checked against a bounded passive-artwork allowlist before rasterization or persistence. Active content, scripts, event handlers, external resources, embedded HTML/images, animation and unsafe XML constructs are rejected. Supported editable shape geometry is retained. No provider SVG is inserted as HTML. SVG media responses receive a restrictive Content Security Policy and `X-Content-Type-Options: nosniff`.

Each result stores a canonical PNG `url` and editable `svgUrl`, both in the attached workflow's `outputs/` directory or ordinary app outputs. Edited results also store `alphaUrl` and source SVG lineage. Recursive workflow asset collection copies these, applied look references and draft source URLs during Save As and rewrites them on package import. Removing the node's download buttons does not remove these files or alter layer saves. Output Original exports the canonical PNG; its explicit SVG format validates and exports the SVG companion, and Alpha matte extracts the canonical PNG's transparency. Neither option changes the saved source or overwrites an existing delivery.
